@@ mod.re.syntax
Q: What do the regular expression symbols mean (. * + ? [] \d \w ^ $ |)?
aka: regex cheat sheet, regex syntax, regex symbols, \d \w \s, quantifiers, character class, anchors, regex basics
A: `.` any character; `\d` digit, `\w` letter/digit/_, `\s` whitespace (capitals = NOT); `[abc]` one of, `[^abc]` none of, `[a-z]` range; `*` 0+, `+` 1+, `?` 0 or 1, `{3}` exactly 3, `{2,5}` 2–5; `^` start, `$` end, `\b` word edge; `a|b` either; `( )` group. Always write patterns as raw strings `r"..."`.
see: py.regex
```py
import re
text = "Call 555-1234 or 555-9876 before 9am, ref AB12."
print(re.findall(r"\d{3}-\d{4}", text))
print(re.findall(r"\b[A-Z]{2}\d+\b", text))
print(re.findall(r"\b\w{4}\b", text))
print(bool(re.fullmatch(r"[a-z]+\d?", "abc7")), bool(re.fullmatch(r"[a-z]+\d?", "abc77")))
```
```text
['555-1234', '555-9876']
['AB12']
['Call', '1234', '9876', 'AB12']
True False
```

@@ mod.re.functions
Q: What's the difference between re.match, re.search, re.fullmatch, re.findall and re.finditer?
aka: match vs search, fullmatch, findall vs finditer, re functions list, which re function
A: `match` = only at the **start**; `search` = first match **anywhere**; `fullmatch` = the **whole** string must match (validation); `findall` = list of all matches (strings or group tuples); `finditer` = match objects one by one (with positions). `split` and `sub` split and replace.
see: py.err2.re-none-group
```py
import re
s = "id42 and id7"
print(re.match(r"\d+", s), re.search(r"\d+", s).group(), re.fullmatch(r"id\d+", "id42") is not None)
print(re.findall(r"id(\d+)", s), [(m.group(), m.start()) for m in re.finditer(r"\d+", s)])
print(re.split(r"\s*and\s*", s), re.sub(r"\d+", "#", s))
```
```text
None 42 True
['42', '7'] [('42', 2), ('7', 11)]
['id42', 'id7'] id# and id#
```

@@ mod.re.groups
Q: How do I pull parts out of a match (groups, named groups)?
aka: regex groups, capture groups, named groups, group(1), groupdict, extract with regex, non capturing group
A: Brackets capture: `m.group(1)`, `m.groups()`. Name them with `(?P<name>...)` and read `m["name"]` or `m.groupdict()`. `(?:...)` groups without capturing.
see: mod.re.functions
```py
import re
log = "2026-03-09 14:05:07 ERROR disk full"
m = re.match(r"(?P<date>\d{4}-\d{2}-\d{2}) (?P<time>[\d:]+) (?P<level>[A-Z]+) (?P<msg>.*)", log)
print(m["level"], m["msg"])
print(m.groupdict())
print(re.findall(r"(?:Mr|Ms|Dr)\.? (\w+)", "Dr Who met Ms. Marple and Mr Bean"))
```
```text
ERROR disk full
{'date': '2026-03-09', 'time': '14:05:07', 'level': 'ERROR', 'msg': 'disk full'}
['Who', 'Marple', 'Bean']
```

@@ mod.re.sub-func
Q: How do I replace with a function or reuse matched text in the replacement (re.sub)?
aka: re sub, regex replace, backreference replacement, \1 in replacement, replace with function, re.sub callback
A: In the replacement, `\1` (or `\g<name>`) inserts a group. Pass a **function** instead to compute each replacement from the match object.
see: mod.re.groups
```py
import re
print(re.sub(r"(\d{2})/(\d{2})/(\d{4})", r"\3-\2-\1", "due 25/12/2026"))
print(re.sub(r"\b(\w)(\w*)", lambda m: m[1].upper() + m[2].lower(), "hELLO wORLD"))
prices = "apple 1.50, pear 0.80"
print(re.sub(r"\d+\.\d+", lambda m: f"{float(m[0]) * 1.2:.2f}", prices))
print(re.subn(r"o", "0", "foo boo"))
```
```text
due 2026-12-25
Hello World
apple 1.80, pear 0.96
('f00 b00', 4)
```

@@ mod.re.flags
Q: How do I make a regex case-insensitive, multi-line, or readable with comments (flags)?
aka: regex flags, ignorecase, re.I, multiline, re.M, dotall, re.S, verbose regex, re.X
A: `re.IGNORECASE` (`re.I`) ignores case; `re.MULTILINE` (`re.M`) makes `^`/`$` match at every line; `re.DOTALL` (`re.S`) lets `.` match newlines; `re.VERBOSE` (`re.X`) allows spaces and `#` comments in the pattern. Combine with `|`.
see: mod.re.syntax
```py
import re
text = "Apple\nbanana\nAvocado"
print(re.findall(r"^a\w+", text, re.I | re.M))
pattern = re.compile(r"""
    (?P<user>[\w.+-]+)   # name part
    @
    (?P<domain>[\w-]+(?:\.[\w-]+)+)   # domain with at least one dot
""", re.X)
m = pattern.fullmatch("ada.l+test@maths.ac.uk")
print(m["user"], m["domain"])
```
```text
['Apple', 'Avocado']
ada.l+test maths.ac.uk
```

@@ mod.re.greedy
Q: Why does my regex match too much (greedy vs lazy)?
aka: greedy regex, lazy regex, non greedy, .*?, match too much, shortest match
A: `*`, `+`, `{}` are **greedy**: they take as much as possible. Add `?` to make them lazy (`.*?`, `+?`) so they stop at the first chance. Even better, use a negated class like `[^>]*`.
see: mod.re.syntax
```py
import re
html = "<b>bold</b> and <i>italic</i>"
print(re.findall(r"<.*>", html))
print(re.findall(r"<.*?>", html))
print(re.findall(r"<([^>]+)>", html))
```
```text
['<b>bold</b> and <i>italic</i>']
['<b>', '</b>', '<i>', '</i>']
['b', '/b', 'i', '/i']
```

@@ mod.re.common
Q: What are good regex patterns for emails, phone numbers, URLs, dates and postcodes?
aka: email regex, phone regex, url regex, date regex, postcode regex, validate with regex, common regex patterns
A: Simple, practical patterns (real validation often needs more: for emails, send a confirmation link). Use `fullmatch` to validate a whole string, `findall` to extract.
see: mod.re.flags
```py
import re
PATTERNS = {
    "email": r"[\w.+-]+@[\w-]+(\.[\w-]+)+",
    "uk_postcode": r"[A-Z]{1,2}\d[A-Z\d]? ?\d[A-Z]{2}",
    "iso_date": r"\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])",
    "time_24h": r"([01]\d|2[0-3]):[0-5]\d",
    "hex_colour": r"#([0-9a-fA-F]{3}|[0-9a-fA-F]{6})",
    "url": r"https?://[\w.-]+(/[\w./?%&=-]*)?",
}
tests = {"email": "a.b@ex.co.uk", "uk_postcode": "SW1A 1AA", "iso_date": "2026-02-30",
         "time_24h": "23:59", "hex_colour": "#c23b22", "url": "https://python.org/doc"}
for name, value in tests.items():
    print(f"{name:<12} {value:<22} {bool(re.fullmatch(PATTERNS[name], value))}")
```
```text
email        a.b@ex.co.uk           True
uk_postcode  SW1A 1AA               True
iso_date     2026-02-30             True
time_24h     23:59                  True
hex_colour   #c23b22                True
url          https://python.org/doc True
```
Note `2026-02-30` passes the pattern but isn't a real date: check dates with `datetime.strptime`.

@@ mod.re.compile
Q: Should I use re.compile?
aka: re compile, compiled pattern, regex performance, reuse pattern
A: It's optional: Python caches recently used patterns. `re.compile` is nice for naming a pattern used in several places and lets you call `.search`, `.findall`, `.sub` on it.
see: mod.re.functions
```py
import re
WORD = re.compile(r"[a-z']+", re.I)
text = "It's a lovely day, isn't it?"
print(WORD.findall(text), len(WORD.findall(text)), WORD.pattern)
```
```text
["It's", 'a', 'lovely', 'day', "isn't", 'it'] 6 [a-z']+
```

@@ mod.re.escape
Q: How do I search for text that contains special characters like . ? ( + $ in a regex?
aka: escape regex special characters, re.escape, literal dot regex, search for question mark, special characters regex
A: Put a backslash before them (`\.`, `\?`, `\(`), or let `re.escape(text)` do it for text that comes from a user.
see: mod.re.syntax
```py
import re
price = "$4.99 (sale)"
print(re.findall(r"\$\d+\.\d+", price))
user_text = "(sale)"
print(re.escape(user_text), bool(re.search(re.escape(user_text), price)))
```
```text
['$4.99']
\(sale\) True
```

@@ mod.re.lookaround
Q: What are lookahead and lookbehind (match only if followed/preceded by something)?
aka: lookahead, lookbehind, positive lookahead, negative lookahead, password regex lookahead, (?=, (?<=, (?!
A: `(?=...)` = followed by, `(?!...)` = not followed by, `(?<=...)` = preceded by, `(?<!...)` = not preceded by. They check without including that text in the match. Classic use: password rules.
see: mod.re.common
```py
import re
print(re.findall(r"\d+(?=€)", "10€ 20$ 30€"))
print(re.findall(r"(?<=\$)\d+", "10€ $20 $30"))
strong = re.compile(r"(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}")
print([bool(strong.fullmatch(p)) for p in ("password", "Passw0rd", "Pa1")])
```
```text
['10', '30']
['20', '30']
[False, True, False]
```

@@ mod.re.split-tokens
Q: How do I split text on several different separators (or keep the separators)?
aka: split multiple delimiters, re split, split on comma or semicolon, tokenize, split keep delimiters
A: `re.split(r"[,;\s]+", text)` splits on any of them. Put the separator pattern in brackets to **keep** the separators in the result.
see: py.split
```py
import re
print(re.split(r"[,;|\s]+", "a, b;c |d   e"))
print(re.split(r"([+\-*/])", "12+3*4-5"))
print(re.findall(r"\d+\.?\d*|[+\-*/()]", "3.5*(2+10)"))
```
```text
['a', 'b', 'c', 'd', 'e']
['12', '+', '3', '*', '4', '-', '5']
['3.5', '*', '(', '2', '+', '10', ')']
```

@@ mod.re.extract-numbers
Q: How do I get all the numbers (including decimals and negatives) out of text?
aka: extract numbers from string, find all numbers, numbers in text, parse numbers regex, get digits from string
A: `re.findall(r"-?\d+(?:\.\d+)?", text)` then convert with `float`. For just digits: `"".join(filter(str.isdigit, text))`.
see: mod.re.common
```py
import re
text = "Temp -3.5°C, wind 12 km/h, rain 0.8mm on day 4"
nums = [float(n) for n in re.findall(r"-?\d+(?:\.\d+)?", text)]
print(nums, sum(nums))
print("".join(filter(str.isdigit, "Phone: (020) 7946-0958")))
```
```text
[-3.5, 12.0, 0.8, 4.0] 13.3
02079460958
```
