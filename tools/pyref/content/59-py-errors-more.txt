@@ py.err2.no-attr-split

```py
print(words, d)
```

@@ py.err2.tab-error

aka: taberror, inconsistent tabs spaces, mixed tabs and spaces, indentation tabs, convert tabs to spaces
err: inconsistent use of tabs and spaces in indentation
A: Some lines are indented with tabs and others with spaces. Make the whole file use spaces (4 per level): most editors have "Convert indentation to spaces"; IDLE has Format → Untabify Region.
see: py.indentation, py.err.indentation
```py
source = "def f():\n\tif True:\n        return 1\n"      # line 2 uses a tab

    if "\t" in indent:
        print(f"line {n} is indented with a tab")
fixed = source.replace("\t", "    ")                    # tabs -> 4 spaces
exec(fixed)
print(f())
```
