@@ py.bi.overview
Q: Which functions are built into Python (no import needed)?
aka: built in functions list, builtins, functions without import, all python functions, dir(builtins)
A: About 70: `abs aiter all anext any ascii bin bool breakpoint bytearray bytes callable chr classmethod compile complex delattr dict dir divmod enumerate eval exec filter float format frozenset getattr globals hasattr hash help hex id input int isinstance issubclass iter len list locals map max memoryview min next object oct open ord pow print property range repr reversed round set setattr slice sorted staticmethod str sum super tuple type vars zip`. Each has an answer in this section.
```py
import builtins
names = [n for n in dir(builtins) if n[0].islower() and not n.startswith("_") and callable(getattr(builtins, n))]
print(len(names), names[:6])
```

@@ py.bi.all-any
Q: all() and any(): check every / at least one item
aka: all function, any function, all true, any true, check list condition, all empty list
A: `all(it)` is True if every item is truthy (and for an empty list); `any(it)` is True if at least one is (False for empty). Pass a generator to check a condition.
see: py.list-any-all
```py
marks = [72, 85, 90]
print(all(m >= 50 for m in marks), any(m == 100 for m in marks))
print(all([]), any([]), any(["", 0, "x"]))
```

```text
True False True
```

@@ py.bi.breakpoint
Q: breakpoint(): stop and inspect the program (debugger)
aka: breakpoint, pdb, debugger, pause program, step through code, inspect variables
A: `breakpoint()` pauses at that line and opens the debugger (`pdb`) in the terminal. Type `p name` to print a variable, `n` next line, `s` step into, `c` continue, `q` quit. Editors like VS Code and Thonny have friendlier debuggers.
see: py.debug-print
```py norun
def average(nums):
    total = sum(nums)

    return total / len(nums)

average([3, 4, 5])
```

@@ py.bi.compile-eval-exec
Q: eval(), exec() and compile(): run code from a string (and why to be careful)
aka: eval, exec, compile, run string as code, evaluate expression string, calculator eval, eval dangerous
A: `eval("2 + 3")` evaluates an **expression** and returns the value; `exec(code)` runs **statements**; `compile` prepares code for either. **Never** eval text from users: it can run any command. For maths input, parse it yourself or use `ast.literal_eval` for literal values.
see: mod.ast.literal-eval
```py
import ast
print(eval("2 + 3 * 4"))
scope = {}
exec("x = 10\ny = x * 2", scope)
print(scope["y"])
print(ast.literal_eval("[1, 2, {'a': 3}]"))      # safe: only literals allowed
try:
    ast.literal_eval("__import__('os')")
except ValueError as e:
    print("refused:", type(e).__name__)
```
```text
14
20
[1, 2, {'a': 3}]
refused: ValueError
```

@@ py.bi.filter-map
Q: filter() and map(): apply a function to every item / keep matching items
aka: map function, filter function, map with lambda, filter none, map multiple lists
A: `map(f, items)` gives `f(item)` for each; with two lists, `f(a, b)` pairwise. `filter(f, items)` keeps items where `f(item)` is truthy; `filter(None, items)` drops falsy ones. Both are lazy: wrap in `list()` to see them.
see: py.map-filter
```py
print(list(map(int, ["1", "2", "3"])))
print(list(map(pow, [2, 3], [5, 2])))
print(list(filter(str.isdigit, ["1", "a", "22"])), list(filter(None, [0, 1, "", "x"])))
```
```text
[1, 2, 3]
[32, 9]
['1', '22'] [1, 'x']
```

@@ py.bi.hash-id
Q: hash() and id(): an object's hash and identity
aka: hash function, id function, object identity, memory address, unhashable
A: `id(x)` is a number unique to that object while it lives (`a is b` compares ids). `hash(x)` is used by sets and dicts; only unchanging (immutable) values have one.

```py

try:
    hash([1, 2])
except TypeError as e:
    print(e)
```
```text

True True
unhashable type: 'list'
```

@@ py.bi.sum
Q: sum(): add up numbers (with a start value)
aka: sum function, sum of list, sum start, sum floats exactly, sum of column
A: `sum(numbers, start=0)`. Since Python 3.12, `sum` of floats is carefully rounded (older versions gave `0.9999999999999999` for ten 0.1s; `math.fsum` is exact on every version). Don't use `sum` to join strings: use `"".join(...)`.
see: py.list-math
```py
import math
print(sum([1, 2, 3]), sum([1, 2], start=10), sum(x * x for x in range(4)))
print(sum([0.1] * 10), math.fsum([0.1] * 10))
```

@@ py.bi.zip
Q: zip(): pair up items from several lists
aka: zip function, zip lists, zip strict, unzip
A: `zip(a, b)` yields tuples `(a[0], b[0]), ...` and stops at the shortest; `strict=True` errors on different lengths.

```py
print(list(zip("abc", [1, 2, 3])), dict(zip(["x", "y"], [9, 8])))
```

@@ py.bi.aiter-anext
Q: aiter() and anext(): async versions of iter and next
aka: aiter, anext, async iterator, async for, async generator next
A: The same idea as `iter`/`next` for async iterators, used inside `async` code.
see: mod.asyncio.basics
```py
import asyncio

async def ticks(n):
    for i in range(n):
        await asyncio.sleep(0)
        yield i

async def main():
    it = aiter(ticks(3))
    print(await anext(it), await anext(it), await anext(it), await anext(it, "end"))

asyncio.run(main())
```
```text
0 1 2 end
```

@@ py.bi.getattr-family

```py
class C: pass
```


@@ py.bi.exit-quit
Q: exit(), quit(), copyright(), credits(), license(): the shell helpers
