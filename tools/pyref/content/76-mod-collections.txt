@@ mod.collections.counter
Q: What can collections.Counter do (beyond counting)?
aka: Counter methods, most_common, counter arithmetic, counter update, counter subtract, elements, total
A: Counts anything hashable. `most_common(n)`, `update(more)`, `subtract(other)`, `total()` (3.10+), `elements()`, and maths between counters: `+`, `-` (drops zero/negative), `&` (min), `|` (max). Missing keys count as 0.
see: py.counter
```py
from collections import Counter
inv = Counter(apple=3, pear=1)
inv.update(["apple", "fig"])
print(inv, inv["banana"], inv.total())
need = Counter(apple=5, fig=1)
print(need - inv, inv & need, sorted(inv.elements()))
```
```text
Counter({'apple': 4, 'pear': 1, 'fig': 1}) 0 6
Counter({'apple': 1}) Counter({'apple': 4, 'fig': 1}) ['apple', 'apple', 'apple', 'apple', 'fig', 'pear']
```

@@ mod.collections.defaultdict
Q: How does defaultdict work (with list, int, set, or nested)?
aka: defaultdict, default dict list, defaultdict int, nested defaultdict, auto create key, group items
A: `defaultdict(factory)` creates a missing key's value by calling `factory()` when you first use it: `list` → `[]`, `int` → `0`, `set` → `set()`. A lambda makes nested ones.
see: py.defaultdict, py.coll.invert-dict
```py
from collections import defaultdict
words = ["apple", "avocado", "banana", "blueberry", "cherry"]
by_letter = defaultdict(list)
for w in words:
    by_letter[w[0]].append(w)
print(dict(by_letter))
counts = defaultdict(int)
for ch in "hello":
    counts[ch] += 1
print(dict(counts))
tree = defaultdict(lambda: defaultdict(int))
tree["2026"]["Mar"] += 5
print({k: dict(v) for k, v in tree.items()})
```
```text
{'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
{'h': 1, 'e': 1, 'l': 2, 'o': 1}
{'2026': {'Mar': 5}}
```

@@ mod.collections.deque
Q: What is a deque and when should I use it (queues, last N items)?
aka: deque, double ended queue, appendleft, popleft, maxlen, last n items, sliding window deque, rotate
A: A list-like sequence that adds/removes quickly at **both** ends: `append`, `appendleft`, `pop`, `popleft`, `rotate`. With `maxlen=n` it keeps only the last n items (old ones fall off), perfect for recent history.
see: py.coll.stack-queue
```py
from collections import deque
q = deque(["a", "b"])
q.appendleft("start"); q.append("end")
print(q.popleft(), q.pop(), list(q))
recent = deque(maxlen=3)
for page in ["home", "about", "blog", "contact"]:
    recent.append(page)
print(list(recent))
```
```text
start end ['a', 'b']
['about', 'blog', 'contact']
```

@@ mod.collections.chainmap
Q: How do I look up a setting in several dicts in order (defaults, config file, command line)?
aka: chainmap, layered settings, default config override, multiple dicts lookup
A: `ChainMap(cli, user, defaults)` searches the dicts left to right and returns the first hit, without copying them.
see: py.dict-merge
```py
from collections import ChainMap
defaults = {"theme": "light", "size": 12, "lang": "en"}
user = {"size": 14}
cli = {"theme": "dark"}
settings = ChainMap(cli, user, defaults)
print(settings["theme"], settings["size"], settings["lang"], dict(settings))
```
```text
dark 14 en {'theme': 'dark', 'size': 14, 'lang': 'en'}
```

@@ mod.itertools.basics
Q: What's in itertools (the most useful tools)?
aka: itertools, itertools functions, chain, islice, accumulate, groupby, product, permutations, combinations, batched, takewhile
A: Combining: `chain`, `zip_longest`, `product`. Slicing: `islice`, `takewhile`, `dropwhile`, `batched` (3.12+). Running totals: `accumulate`. Grouping: `groupby`. Arranging: `permutations`, `combinations`, `combinations_with_replacement`. Endless: `count`, `cycle`, `repeat`.
see: py.it.infinite, mod.itertools.combos
```py
from itertools import accumulate, batched, chain, dropwhile, islice, takewhile
print(list(chain([1, 2], "ab")), list(islice("abcdefg", 2, 6, 2)))
print(list(accumulate([3, 1, 4, 1, 5])), list(accumulate([3, 1, 4], max)))
print(list(takewhile(lambda x: x < 3, [1, 2, 5, 1])), list(dropwhile(lambda x: x < 3, [1, 2, 5, 1])))
print(list(batched("abcdefg", 3)))
```
```text
[1, 2, 'a', 'b'] ['c', 'e']
[3, 4, 8, 9, 14] [3, 3, 4]
[1, 2] [5, 1]
[('a', 'b', 'c'), ('d', 'e', 'f'), ('g',)]
```

@@ mod.itertools.combos
Q: How do I get all combinations, permutations or pairs of items?
aka: combinations, permutations, all pairs, product, every combination, cartesian product, anagrams
A: `combinations(items, r)` = choose r, order doesn't matter; `permutations(items, r)` = order matters; `product(a, b)` = every pairing (like nested loops); `product("01", repeat=3)` = all 3-digit binary strings.
see: mod.itertools.basics
```py
from itertools import combinations, permutations, product
print(list(combinations("ABC", 2)))
print(["".join(p) for p in permutations("abc")])
print(list(product([1, 2], "xy")))
print(["".join(p) for p in product("01", repeat=3)])
print(len(list(combinations(range(49), 6))))          # lottery tickets
```
```text
[('A', 'B'), ('A', 'C'), ('B', 'C')]
['abc', 'acb', 'bac', 'bca', 'cab', 'cba']
[(1, 'x'), (1, 'y'), (2, 'x'), (2, 'y')]
['000', '001', '010', '011', '100', '101', '110', '111']
13983816
```

@@ mod.itertools.groupby
Q: How does itertools.groupby work (and why does it give repeated groups)?
aka: groupby, group consecutive items, groupby sorted, run length encoding, groupby key
A: `groupby` groups **consecutive** items with the same key. Sort by the same key first if you want one group per key. It's great for run-length encoding.
see: py.coll.invert-dict
```py
from itertools import groupby
words = ["apple", "avocado", "banana", "apricot"]
print([(k, list(g)) for k, g in groupby(words, key=lambda w: w[0])])
print([(k, list(g)) for k, g in groupby(sorted(words), key=lambda w: w[0])])
print("".join(f"{k}{len(list(g))}" for k, g in groupby("aaabccdddd")))
```
```text
[('a', ['apple', 'avocado']), ('b', ['banana']), ('a', ['apricot'])]
[('a', ['apple', 'apricot', 'avocado']), ('b', ['banana'])]
a3b1c2d4
```

@@ mod.functools.reduce
Q: What does functools.reduce do?
aka: reduce, fold, combine list to one value, reduce lambda, product of list
A: `reduce(f, items, start)` combines items pairwise left to right: `f(f(f(start, a), b), c)`. Often a built-in is clearer (`sum`, `math.prod`, `max`, `"".join`).
see: mod.functools.overview
```py
import math
from functools import reduce
print(reduce(lambda a, b: a * b, [1, 2, 3, 4]), math.prod([1, 2, 3, 4]))
print(reduce(lambda acc, d: acc * 10 + d, [4, 0, 2], 0))
merged = reduce(lambda a, b: a | b, [{"a": 1}, {"b": 2}, {"a": 3}])
print(merged)
```
```text
24 24
402
{'a': 3, 'b': 2}
```

@@ mod.functools.overview
Q: What's in functools (cache, lru_cache, partial, wraps, total_ordering, singledispatch)?
aka: functools module, functools list, cache decorator, lru_cache maxsize, cmp_to_key, cached_property
A: `cache`/`lru_cache(maxsize=n)` memoise results; `partial` pre-fills arguments; `wraps` for decorators; `total_ordering` fills comparisons; `singledispatch` picks a function by argument type; `cached_property`; `reduce`; `cmp_to_key` turns an old-style compare function into a sort key.
see: py.fn.partial, py.fn.recursion-memo, py.deco.builtin
```py
from functools import cmp_to_key, lru_cache

@lru_cache(maxsize=128)
def slow_square(n):
    return n * n

[slow_square(i % 5) for i in range(100)]
print(slow_square.cache_info())

def by_length_then_alpha(a, b):
    return (len(a) > len(b)) - (len(a) < len(b)) or (a > b) - (a < b)
print(sorted(["bb", "a", "ccc", "ab"], key=cmp_to_key(by_length_then_alpha)))
```
```text
CacheInfo(hits=95, misses=5, maxsize=128, currsize=5)
['a', 'ab', 'bb', 'ccc']
```

@@ mod.operator
Q: What are operator.itemgetter, attrgetter and methodcaller?
aka: operator module, itemgetter, attrgetter, methodcaller, operator add, sort key without lambda
A: Small ready-made functions: `itemgetter(1)` ≈ `lambda x: x[1]`; `attrgetter("age")` ≈ `lambda o: o.age`; `methodcaller("lower")` ≈ `lambda s: s.lower()`; `operator.add`, `mul`... are the operators as functions. They're quick and readable as sort keys.
see: py.it.sort-multi
```py
from operator import attrgetter, itemgetter, methodcaller, mul
from functools import reduce
from types import SimpleNamespace as NS

pairs = [("b", 2), ("a", 3), ("c", 1)]
print(sorted(pairs, key=itemgetter(1)), list(map(itemgetter(0), pairs)))
people = [NS(name="Ada", age=36), NS(name="Sam", age=14)]
print([p.name for p in sorted(people, key=attrgetter("age"))])
print(list(map(methodcaller("upper"), ["x", "y"])), reduce(mul, [2, 3, 4]))
```
```text
[('c', 1), ('b', 2), ('a', 3)] ['b', 'a', 'c']
['Sam', 'Ada']
['X', 'Y'] 24
```

@@ mod.heapq
Q: How do I get the smallest/largest N items fast, or keep a priority queue (heapq)?
aka: heapq, priority queue, nlargest, nsmallest, heap push pop, top n items, min heap
A: `heapq.nlargest(n, items, key=)` / `nsmallest` for top-N. For a priority queue, keep a list and use `heappush(h, (priority, item))` and `heappop(h)` (smallest priority first).
see: py.coll.choose
```py
import heapq
scores = {"Ada": 91, "Sam": 78, "Kai": 88, "Bo": 95}
print(heapq.nlargest(2, scores, key=scores.get), heapq.nsmallest(2, [5, 1, 8, 3]))
jobs = []
heapq.heappush(jobs, (2, "write report"))
heapq.heappush(jobs, (1, "fix bug"))
heapq.heappush(jobs, (3, "lunch"))
print([heapq.heappop(jobs)[1] for _ in range(len(jobs))])
```
```text
['Bo', 'Ada'] [1, 3]
['fix bug', 'write report', 'lunch']
```

@@ mod.bisect
Q: How do I find where to insert into a sorted list, or turn a score into a grade (bisect)?
aka: bisect, binary search, insort, sorted insert, grade boundaries, search sorted list
A: `bisect.bisect(sorted_list, x)` returns the position where `x` would go (fast binary search); `insort(list, x)` inserts keeping it sorted. Lovely for mapping numbers to bands.
see: py.coll.choose
```py
import bisect
def grade(score, bounds=[50, 60, 70, 80], letters="FDCBA"):
    return letters[bisect.bisect(bounds, score)]
print([grade(s) for s in (33, 50, 69, 70, 99)])
xs = [10, 20, 30]
bisect.insort(xs, 25)
print(xs, bisect.bisect_left(xs, 20), bisect.bisect_right(xs, 20))
```
```text
['F', 'D', 'C', 'B', 'A']
[10, 20, 25, 30] 1 2
```

@@ mod.statistics
Q: What can the statistics module calculate (mean, median, mode, stdev, correlation, regression)?
aka: statistics module, median, mode, standard deviation, variance, correlation, linear regression, fmean, harmonic mean
A: `mean`, `fmean` (faster float mean), `median`, `median_low/high`, `mode`, `multimode`, `stdev`/`pstdev`, `variance`, `quantiles`, `harmonic_mean`, `geometric_mean`, and since 3.10 `correlation` and `linear_regression`.
see: py.num.statistics
```py
import statistics as st
hours = [1, 2, 3, 4, 5]
marks = [52, 58, 65, 70, 79]
print(st.fmean(marks), st.median(marks), st.multimode([1, 1, 2, 2, 3]))
print(round(st.correlation(hours, marks), 3))
fit = st.linear_regression(hours, marks)
print(round(fit.slope, 2), round(fit.intercept, 2), "predict 6h:", round(fit.slope * 6 + fit.intercept))
```
```text
64.8 65 [1, 2]
0.996
6.6 45.0 predict 6h: 85
```

import math
