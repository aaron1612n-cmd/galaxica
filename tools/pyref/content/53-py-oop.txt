@@ py.oop.eq-hash
Q: How do I make two objects equal when their data is equal (and use them in sets/dict keys)?
aka: __eq__, __hash__, compare objects, object equality, unhashable type custom class, objects in set, equal objects not equal
A: By default objects are only equal to themselves. Define `__eq__` to compare data. If you define `__eq__`, also define `__hash__` (from the same fields, which should not change) so they work in sets and as dict keys. `@dataclass(frozen=True)` does both for you.
see: py.dunder, py.dataclass
```py
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)
    def __hash__(self):
        return hash((self.x, self.y))

print(Point(1, 2) == Point(1, 2), Point(1, 2) is Point(1, 2))
print(len({Point(1, 2), Point(1, 2), Point(3, 4)}))
```
```text
True False
2
```

@@ py.oop.ordering
Q: How do I make my objects sortable (<, >) without writing every comparison?
aka: total_ordering, __lt__, sort objects, compare objects less than, sortable class
A: Define `__eq__` and `__lt__`, then add `@functools.total_ordering` to get `<=`, `>`, `>=` for free. Or use `@dataclass(order=True)` (compares fields in order). For a one-off sort, `key=` is simpler.
see: py.oop.eq-hash, py.it.reversed-sorted
```py
from dataclasses import dataclass
from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, s):
        self.parts = tuple(int(p) for p in s.split("."))
    def __eq__(self, other):
        return self.parts == other.parts
    def __lt__(self, other):
        return self.parts < other.parts
    def __repr__(self):
        return ".".join(map(str, self.parts))

print(sorted([Version("1.10.0"), Version("1.2.3"), Version("1.9")]))
print(Version("2.0") >= Version("1.99"))

@dataclass(order=True)
class Card:
    rank: int
    suit: str
print(max(Card(10, "hearts"), Card(12, "clubs")))
```
```text
[1.2.3, 1.9, 1.10.0]
True
Card(rank=12, suit='clubs')
```

@@ py.oop.operators
Q: Which special methods make + - * / [] in and len work on my objects?
aka: operator overloading list, __add__ __sub__ __mul__, __radd__, __iadd__, __getitem__ __setitem__, __contains__, __bool__, __neg__, dunder methods list
A: Arithmetic: `__add__`, `__sub__`, `__mul__`, `__truediv__`, `__floordiv__`, `__mod__`, `__pow__`, `__neg__`, `__abs__` (plus `__radd__` etc. when your object is on the right, and `__iadd__` for `+=`). Containers: `__len__`, `__getitem__`, `__setitem__`, `__delitem__`, `__contains__` (`in`), `__iter__`. Others: `__bool__`, `__call__`, `__str__`, `__repr__`, `__format__`.
see: py.dunder
```py
class Vec:
    def __init__(self, x, y): self.x, self.y = x, y
    def __add__(self, o):     return Vec(self.x + o.x, self.y + o.y)
    def __sub__(self, o):     return Vec(self.x - o.x, self.y - o.y)
    def __mul__(self, k):     return Vec(self.x * k, self.y * k)
    __rmul__ = __mul__                       # so 3 * v works too
    def __neg__(self):        return Vec(-self.x, -self.y)
    def __abs__(self):        return (self.x ** 2 + self.y ** 2) ** 0.5
    def __bool__(self):       return bool(self.x or self.y)
    def __getitem__(self, i): return (self.x, self.y)[i]
    def __len__(self):        return 2
    def __repr__(self):       return f"Vec({self.x}, {self.y})"

a, b = Vec(1, 2), Vec(3, 4)
print(a + b, b - a, a * 3, 3 * a, -a)
print(abs(b), bool(Vec(0, 0)), b[0], len(b), list(b))
```
```text
Vec(4, 6) Vec(2, 2) Vec(3, 6) Vec(3, 6) Vec(-1, -2)
5.0 False 3 2 [3, 4]
```

@@ py.oop.container
Q: How do I make a class that behaves like a list or dict (indexing, len, in)?
aka: custom container, class like list, __getitem__ __setitem__, subclass list, subclass dict, UserDict, collection class
A: Either define `__len__`, `__getitem__`, `__setitem__`, `__contains__`, `__iter__` yourself, or **subclass** `list`/`dict` (or `collections.UserDict`/`UserList`, which are easier to customise safely).
see: py.oop.operators
```py
from collections import UserDict

class CaseInsensitiveDict(UserDict):
    def __setitem__(self, key, value):
        super().__setitem__(key.lower(), value)
    def __getitem__(self, key):
        return super().__getitem__(key.lower())
    def __contains__(self, key):
        return key.lower() in self.data

class Playlist:
    def __init__(self, *songs): self.songs = list(songs)
    def __len__(self): return len(self.songs)
    def __getitem__(self, i): return self.songs[i]        # also makes slicing and for-loops work
    def __contains__(self, s): return s in self.songs

d = CaseInsensitiveDict()
d["Content-Type"] = "text/html"
print(d["content-type"], "CONTENT-TYPE" in d)
p = Playlist("a", "b", "c")
print(len(p), p[-1], p[:2], "b" in p, [s for s in p])
```
```text
text/html True
3 c ['a', 'b'] True ['a', 'b', 'c']
```

@@ py.oop.abstract
Q: How do I make an abstract base class (a class that must be subclassed)?
aka: abstract class, abc module, abstractmethod, interface python, must implement method, cannot instantiate abstract class
A: Inherit from `abc.ABC` and mark methods with `@abstractmethod`. You can't create the base class itself, and subclasses can't be created until they implement every abstract method.
see: py.inheritance
```py
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self): ...
    def describe(self):
        return f"{type(self).__name__} with area {self.area():.1f}"

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14159 * self.r ** 2

class Square(Shape):
    def __init__(self, s): self.s = s
    def area(self): return self.s ** 2

for s in (Circle(1), Square(3)):
    print(s.describe())
try:
    Shape()
except TypeError as e:
    print(e)
```
```text
Circle with area 3.1
Square with area 9.0
Can't instantiate abstract class Shape without an implementation for abstract method 'area'
```

@@ py.oop.mro
Q: How does multiple inheritance work (MRO, super() with several parents)?
aka: multiple inheritance, method resolution order, mro, diamond problem, super multiple inheritance, mixin order
A: Python searches classes in the **MRO** (`Class.__mro__`): the class, then its parents left to right, never visiting a shared ancestor until all its children are done. `super()` calls the **next** class in the MRO, not necessarily the parent you think, so every class in the chain should call `super()`.
see: py.inheritance, py.oop.mixin
```py
class Base:
    def hello(self):
        return ["Base"]

class A(Base):
    def hello(self):
        return ["A"] + super().hello()

class B(Base):
    def hello(self):
        return ["B"] + super().hello()

class C(A, B):
    def hello(self):
        return ["C"] + super().hello()

print(C().hello())
print([k.__name__ for k in C.__mro__])
```
```text
['C', 'A', 'B', 'Base']
['C', 'A', 'B', 'Base', 'object']
```

@@ py.oop.mixin
Q: What is a mixin class?
aka: mixin, mixin class, add feature to classes, reusable class behaviour, multiple inheritance mixin
A: A small class that adds one ability (e.g. "can be saved as JSON") and is meant to be combined with other classes through multiple inheritance. It usually has no `__init__` of its own.
see: py.oop.mro
```py
import json

class JsonMixin:
    def to_json(self):
        return json.dumps(self.__dict__)

class ReprMixin:
    def __repr__(self):
        fields = ", ".join(f"{k}={v!r}" for k, v in self.__dict__.items())
        return f"{type(self).__name__}({fields})"

class User(JsonMixin, ReprMixin):
    def __init__(self, name, age):
        self.name, self.age = name, age

u = User("Ada", 36)
print(u.to_json())
print(u)
```
```text
{"name": "Ada", "age": 36}
User(name='Ada', age=36)
```

@@ py.oop.factory
Q: How do I give a class several ways to create objects (alternative constructors)?
aka: alternative constructor, classmethod factory, from_string, multiple constructors, overload __init__, from_dict
A: Python has one `__init__`, but you can add `@classmethod` factories like `from_string` or `from_dict` that build the arguments and call `cls(...)`.
see: py.static-classmethod
```py
from datetime import date

class Person:
    def __init__(self, name, born):
        self.name, self.born = name, born

    @classmethod
    def from_string(cls, text):            # "Ada,1815"
        name, year = text.split(",")
        return cls(name, int(year))

    @classmethod
    def from_age(cls, name, age):
        return cls(name, date.today().year - age)

    def __repr__(self):
        return f"Person({self.name!r}, {self.born})"

print(Person.from_string("Ada,1815"))
print(Person.from_age("Sam", 10).name)
```
```text
Person('Ada', 1815)
Sam
```

@@ py.oop.slots
Q: What does __slots__ do?
aka: __slots__, save memory objects, prevent new attributes, slots class, typo attribute protection
A: `__slots__ = ("x", "y")` tells Python the object only has these attributes: it uses less memory (good for millions of objects) and assigning a misspelled attribute raises `AttributeError`.
see: py.dataclass
```py
class Point:
    __slots__ = ("x", "y")
    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
try:
    p.z = 3
except AttributeError as e:
    print(e)
```
```text
'Point' object has no attribute 'z'
```

@@ py.oop.composition
Q: Should I use inheritance or composition ("has a" vs "is a")?
aka: composition vs inheritance, has a relationship, is a relationship, favour composition, object inside object
A: Inherit only when the new class truly **is a** kind of the parent (a `Dog` is an `Animal`). When it just **uses** something (a `Car` has an `Engine`), store that object as an attribute and call it. Composition keeps classes small and easier to change.
see: py.inheritance
```py
class Engine:
    def __init__(self, hp): self.hp = hp
    def start(self): return f"{self.hp}hp engine roars"

class Car:                       # has an Engine, isn't one
    def __init__(self, name, hp):
        self.name = name
        self.engine = Engine(hp)
    def start(self):
        return f"{self.name}: {self.engine.start()}"

print(Car("Mini", 120).start())
```
```text
Mini: 120hp engine roars
```

@@ py.oop.duck
Q: What is duck typing (and how do I check what an object can do)?
aka: duck typing, isinstance vs hasattr, polymorphism python, check if object has method, EAFP
A: Python cares what an object **can do**, not what class it is: anything with a `.read()` works where a file is expected. Just call the method (and catch `AttributeError` if it might be missing), or check with `hasattr`. Use `isinstance` when the type truly matters.
see: py.oop.protocol
```py
import io

def word_count(source):                      # anything with .read() works
    return len(source.read().split())

print(word_count(open("data.txt")))
print(word_count(io.StringIO("one two three four")))

class Robot:
    def speak(self): return "beep"
class Dog:
    def speak(self): return "woof"
print([x.speak() for x in (Robot(), Dog()) if hasattr(x, "speak")])
```
```text
6
4
['beep', 'woof']
```

@@ py.oop.protocol
Q: How do I describe "any object with these methods" for type hints (Protocol)?
aka: typing protocol, structural typing, interface without inheritance, duck typing type hint
A: `typing.Protocol` lists the methods an object must have. Any class with those methods matches, no inheritance needed; type checkers verify it, and `@runtime_checkable` lets `isinstance` check it too.
see: py.oop.duck, py.typing.basics
```py
from typing import Protocol, runtime_checkable

@runtime_checkable
class Drawable(Protocol):
    def draw(self) -> str: ...

class Circle:
    def draw(self) -> str: return "○"

class Text:
    def __init__(self, s): self.s = s
    def draw(self) -> str: return self.s

def render(items: list[Drawable]) -> str:
    return " ".join(i.draw() for i in items)

print(render([Circle(), Text("hi"), Circle()]))
print(isinstance(Circle(), Drawable), isinstance(42, Drawable))
```
```text
○ hi ○
True False
```

@@ py.oop.getattr
Q: How do I get or set an attribute when its name is in a string (getattr, setattr)?
aka: getattr, setattr, hasattr, delattr, attribute name string, dynamic attribute, variable attribute name
A: `getattr(obj, "name")` reads, `getattr(obj, "name", default)` reads with a fallback, `setattr(obj, "name", value)` writes, `hasattr` checks, `delattr` removes. Also works for methods: `getattr(obj, "save")()`.
see: py.oop.dynamic
```py
class Settings:
    volume = 5

s = Settings()
for key, value in {"volume": 8, "theme": "dark"}.items():
    setattr(s, key, value)
print(getattr(s, "volume"), getattr(s, "missing", "default"), hasattr(s, "theme"))
action = "upper"
print(getattr("hello", action)())
```
```text
8 default True
HELLO
```

@@ py.oop.dynamic
Q: How do I run code when a missing attribute is accessed (__getattr__)?
aka: __getattr__, missing attribute fallback, dynamic attributes, proxy object, attribute access hook
A: `__getattr__(self, name)` is called **only** when normal lookup fails, so you can compute or forward attributes (e.g. let `config.port` read `config.data["port"]`). Raise `AttributeError` for truly unknown names.
see: py.oop.getattr
```py
class Config:
    def __init__(self, data):
        self._data = data
    def __getattr__(self, name):
        try:
            return self._data[name]
        except KeyError:
            raise AttributeError(f"no setting {name!r}") from None

c = Config({"host": "localhost", "port": 8080})
print(c.host, c.port)
try:
    c.user
except AttributeError as e:
    print(e)
```
```text
localhost 8080
no setting 'user'
```

@@ py.oop.class-mutable
Q: Why do all my objects share the same list (class attribute bug)?
aka: shared list between instances, class attribute list, all objects same list, class variable mutable bug
A: A list or dict written in the **class body** belongs to the class and is shared by every object. Create per-object lists in `__init__` with `self.items = []`.
see: py.class-vs-instance
```py
class Bad:
    items = []                     # one list for ALL objects
    def add(self, x): self.items.append(x)

class Good:
    def __init__(self):
        self.items = []            # a new list per object
    def add(self, x): self.items.append(x)

a, b = Bad(), Bad(); a.add(1)
c, d = Good(), Good(); c.add(1)
print(b.items, d.items)
```
```text
[1] []
```

@@ py.oop.chaining
Q: How do I let methods be chained (obj.a().b().c())?
aka: method chaining, fluent interface, return self, builder pattern
A: Return `self` from each method that changes the object.
see: py.class-basics
```py
class Query:
    def __init__(self, table):
        self.parts = [f"SELECT * FROM {table}"]
    def where(self, cond):
        self.parts.append(f"WHERE {cond}"); return self
    def order(self, col):
        self.parts.append(f"ORDER BY {col}"); return self
    def limit(self, n):
        self.parts.append(f"LIMIT {n}"); return self
    def __str__(self):
        return " ".join(self.parts)

print(Query("users").where("age > 18").order("name").limit(10))
```
```text
SELECT * FROM users WHERE age > 18 ORDER BY name LIMIT 10
```

@@ py.oop.counter
Q: How do I count how many objects of a class have been made (or give each a unique id)?
aka: count instances, instance counter, unique id per object, class level counter, auto increment id
A: Keep the counter on the **class** (`Class.count += 1` in `__init__`), not on `self`. `itertools.count()` gives neat auto-incrementing ids.
see: py.class-vs-instance
```py
from itertools import count

class Ticket:
    made = 0
    _ids = count(1)
    def __init__(self, title):
        self.id = next(Ticket._ids)
        self.title = title
        Ticket.made += 1

tickets = [Ticket(t) for t in ("bug", "idea", "typo")]
print(Ticket.made, [t.id for t in tickets])
```
```text
3 [1, 2, 3]
```

@@ py.oop.copy
Q: How do I copy an object (shallow vs deep copy)?
aka: copy object, deepcopy, shallow copy, clone object, copy module, copy nested list
A: `copy.copy(x)` makes a new outer object but shares the things inside it; `copy.deepcopy(x)` copies everything inside too. Use deep copies for nested lists/dicts/objects you'll change independently.
see: py.copy-list
```py
import copy

board = [[0, 0], [0, 0]]
shallow = copy.copy(board)
deep = copy.deepcopy(board)
board[0][0] = 9
print(shallow[0][0], deep[0][0])

class Team:
    def __init__(self, members): self.members = members
t1 = Team(["Ada"])
t2 = copy.deepcopy(t1); t2.members.append("Sam")
print(t1.members, t2.members)
```
```text
9 0
['Ada'] ['Ada', 'Sam']
```

@@ py.oop.type-check
Q: What's the difference between type(x) == C and isinstance(x, C)?
aka: isinstance vs type, check type of object, subclass check, issubclass, isinstance multiple types
A: `isinstance(x, C)` is also true for **subclasses** of C (what you usually want) and accepts a tuple of types: `isinstance(x, (int, float))`. `type(x) is C` is exact. `issubclass(A, B)` compares classes.
see: py.types
```py
class Animal: ...
class Dog(Animal): ...

d = Dog()
print(isinstance(d, Animal), type(d) is Animal, type(d) is Dog)
print(isinstance(3.5, (int, float)), issubclass(Dog, Animal))
print(isinstance(True, int))        # bool is a subclass of int!
```
```text
True False True
True True
True
```

@@ py.oop.dataclass-more
Q: What else can dataclasses do (defaults, lists, frozen, post_init, asdict)?
aka: dataclass field default_factory, dataclass list default, frozen dataclass, __post_init__, asdict, dataclass kw_only, dataclass compare
A: `field(default_factory=list)` for list/dict defaults; `frozen=True` makes it read-only (and hashable); `order=True` adds comparisons; `__post_init__` runs after `__init__` (for checks or computed fields); `dataclasses.asdict(obj)` turns it into a dict; `kw_only=True` forces keyword arguments.
see: py.dataclass
```py
from dataclasses import dataclass, field, asdict, replace

@dataclass
class Order:
    customer: str
    items: list[str] = field(default_factory=list)
    total: float = 0.0
    def __post_init__(self):
        if self.total < 0:
            raise ValueError("total can't be negative")

@dataclass(frozen=True)
class Colour:
    r: int
    g: int
    b: int

o = Order("Ada"); o.items.append("tea")
print(asdict(o))
red = Colour(255, 0, 0)
print(replace(red, g=128), {red: "red"}[Colour(255, 0, 0)])
try:
    red.r = 0
except Exception as e:
    print(type(e).__name__)
```
```text
{'customer': 'Ada', 'items': ['tea'], 'total': 0.0}
Colour(r=255, g=128, b=0) red
FrozenInstanceError
```

@@ py.oop.enum
Q: How do I make a fixed set of named constants (Enum)?
aka: enum, enumeration, constants, Enum class, auto, IntEnum, StrEnum, enum value name, loop over enum
A: `class Color(Enum): RED = 1 ...`. Members have `.name` and `.value`, can be looped over, compared with `is`, and looked up by value `Color(1)` or name `Color["RED"]`. `auto()` numbers them for you.
see: py.match
```py
from enum import Enum, auto

class Status(Enum):
    TODO = auto()
    DOING = auto()
    DONE = auto()

s = Status.DOING
print(s, s.name, s.value)
print([m.name for m in Status])
print(Status["DONE"] is Status.DONE, Status(1))
if s is Status.DOING:
    print("in progress")
```
```text
Status.DOING DOING 2
['TODO', 'DOING', 'DONE']
True Status.TODO
in progress
```

@@ py.oop.singleton
Q: How do I make sure only one object of a class exists (singleton)?
aka: singleton, single instance class, one object only, global object, module singleton
A: In Python the simplest singleton is a **module**: import it anywhere and it's the same object. If you need a class, keep the one instance in a class attribute and return it from `__new__`.
see: py.own-module
```py
class Settings:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.volume = 5
        return cls._instance

a = Settings(); b = Settings()
a.volume = 9
print(a is b, b.volume)
```
```text
True 9
```

@@ py.oop.str-repr-format
Q: How do I control how my object looks in f-strings with a format (like {obj:short})?
aka: __format__, custom format spec, format method object, f-string format custom class
A: Define `__format__(self, spec)`: whatever comes after `:` in the f-string is passed as `spec`.
see: py.str-method, py.fmt.spec
```py
class Temp:
    def __init__(self, c): self.c = c
    def __format__(self, spec):
        if spec == "f":
            return f"{self.c * 9 / 5 + 32:.1f}°F"
        return f"{self.c:.1f}°C"

t = Temp(21.5)
print(f"{t} / {t:f}")
```


@@ py.oop.class-properties
Q: How do I make a read-only attribute, or one computed from others?
aka: read only attribute, computed property, property without setter, derived attribute, cached_property
A: `@property` without a setter is read-only. For an expensive value computed once and then remembered, use `@functools.cached_property`.
see: py.property
```py
from functools import cached_property

class Circle:
    def __init__(self, r):
        self.r = r
    @property
    def diameter(self):             # always up to date
        return self.r * 2
    @cached_property
    def heavy(self):                # computed on first use, then stored
        print("computing…")
        return sum(i * self.r for i in range(1000))

c = Circle(2)
print(c.diameter); c.r = 5; print(c.diameter)
print(c.heavy, c.heavy)
try:
    c.diameter = 1
except AttributeError as e:
    print("read-only:", e)
```
```text
4
10
computing…
2497500 2497500
read-only: property 'diameter' of 'Circle' object has no setter
```
